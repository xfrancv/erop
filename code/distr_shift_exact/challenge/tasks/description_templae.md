To format pages, stick to the following conventions:
- Inline `code` should be encapsulated by back-ticks \``. 
- Block code should have  \``` as the first and last line of the block to produce
```
# code to print hello
print('hello')
```
- Subtitles are prefixed with \##


You can display block equations using LaTeX encapsulated between `$$`s, and display inline encapsulated between `\(` and `\)` . Note that underscores should be escaped with a `\` for the LaTeX to render properly. For example, this:

$$ \epsilon = \sqrt{ x\_n^2+1 } $$

is created by this:

`$$  \epsilon = \sqrt{x\_n^2+1} $$`
